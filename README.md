# Monad

## Project Structure

- `frontend/` — Vue 3 + Vite + TypeScript frontend
- `backend/` — Express tabanli Node.js backend
- `contracts/` — Foundry tabanli smart contract workspace

## Getting Started

### Frontend

```sh
cd frontend
npm install
npm run dev
```

### Backend

```sh
cd backend
npm install
npm run dev
```

### Contracts

```sh
cd contracts
forge build
forge test
```
