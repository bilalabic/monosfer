- **Gerçek tarayıcı + çalışan backend ile smoke test gerekli** (bu ortamda Docker/backend yok — yalnız `npm run typecheck`/`eslint` ve boş-backend `npm run dev` boot testi yapılabildi): SIWE wallet login/CSRF/çoklu sekme akışı, `AcceptanceQrScanner.client.vue`'nin gerçek kamera izniyle QR okuma performansı (BarcodeDetector yalnız Chrome/Edge/Android'de var — iOS Safari/Firefox için paste fallback her zaman görünür kalmalı), `DeliveryTrackingMap.client.vue`'nin SSE akışı (`server/middleware/tracking-events-proxy.ts` gerçek `NUXT_REALTIME_ORIGIN`'e karşı test edilmedi — realtime process'in `/v1/deliveries/:id/tracking/events` yolunu birebir aynı path ile sunduğu doğrulanmalı), kurye tarafında `navigator.geolocation.watchPosition` ile konum yayını, ve yeni return (iade) akışı (`requestReturn` → imzalı iade kabulü → `confirmReturn`).

Gerçek response örnekleri görülünce (`backend/artifacts/openapi.json` üretilip incelenebilir) tipleri daraltıp özel alanlara göre biçimlendirilmiş bir görünüme geçirin.
- `app/pages/couriers/index.vue`: `ReputationRegistry`/`BadgeSBT`/`Referral`/`RewardDistributorV1` hâlâ `contracts/exports`'ta ABI/tip olarak yok (contract ekibi CT-CS-1 blokeri — bkz. `contracts/docs/integration.md`). Bu dört isim `contracts/tools/build-exports.mjs`'deki `EXPORTED` listesine eklenip paket yeniden üretilmeden gerçek itibar/rozet/ödül UI'ı bağlanamaz.
